# Smart Campus Management System

## Overview

Smart Campus Management System is a Java-based command-line application designed to simplify campus administration. The system provides modules for managing students, faculty, attendance, complaints, and campus events through an interactive menu-driven interface.

## Features

### Student Management

* Add student records
* View student details
* Update student information
* Delete student records

### Faculty Management

* Add faculty records
* View faculty details
* Update faculty information
* Delete faculty records

### Attendance Management

* Record student attendance
* View attendance records
* Manage attendance data efficiently

### Complaint Management

* Register complaints
* Track complaint records
* Manage complaint information

### Event Management

* Add campus events
* View event details
* Manage event records

### Authentication

* Login system for secure access

## Technologies Used

* Java
* JDBC
* MySQL Database
* Eclipse IDE

## How to Run

### Prerequisites

* Java JDK 8 or above
* MySQL Server
* Eclipse IDE (optional)

### Steps

1. Clone the repository:
   git clone https://github.com/Yaswanth570/Smart_Campus_Management_System.git

2. Open the project in Eclipse or any Java IDE.

3. Configure the database connection in `DBConnection.java`.

4. Create the required MySQL database and tables.

5. Compile and run:
   MainMenu.java
